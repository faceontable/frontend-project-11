# Сохранение учебной сессии: RSS Агрегатор

**Дата:** 14 сентября 2026 г.

## 🎯 Цель проекта
Обучение базовым архитектурным паттернам во фронтенде (MVC / State-driven UI) и работе с современными библиотеками:
- **Valtio**: реактивный стейт-менеджер для управления состоянием формы.
- **Yup**: валидация вводимых URL.
- **Tailwind CSS v4**: утилитарная стилизация интерфейса без написания кастомного CSS.

---

## 🛠 Что уже сделано:
1. **Архитектура (Разделение ответственности)**:
   - Создали прокси-состояние `watchedState` с помощью Valtio.
   - Вынесли обработчик отправки формы (`submit`) в единый слушатель событий, который вешается **один раз** при старте приложения.
   - Создали чистую функцию `renderForm()`, которая подписана через `subscribe` на изменения состояния и занимается исключительно обновлением DOM (без навешивания повторных слушателей).
2. **Стилизация и Окружение**:
   - Очистили файл `src/style.css` от сторонних библиотек и кастомных правил. Оставили только чистый импорт Tailwind v4 и плагина `@tailwindcss/forms`.
   - Создали файл конфигурации `vite.config.js` для корректной сборки плагина `@tailwindcss/vite`.
